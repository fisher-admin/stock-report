# 源码清单

本快照覆盖以下职责：

- 时点股票池、停复牌与历史状态恢复；
- `prebreakout_v43_control`、`prebreakout_v43_top15`、`prebreakout_v44_balanced` 三组短线观察组合；
- `event_quality_drift_v1` 公告事件策略及冻结验证；
- T+1 开盘成交、复权价格、基础/压力成本和组合评价；
- 推荐仓的数据状态、AI 同日证据资格和代理数据禁用；
- 组合级公开结果生成、合同校验、隐私清理与发布防回退；
- 因子工厂的时点股票池、因子面板与正方向晋级闸门；
- 与上述模块对应的单元和集成测试。

为保持公开仓安全，机器专属调度配置、日志、缓存、数据库、数据供应商文件及凭据均不在清单内。GitHub Pages 的前端源代码位于仓库根目录的 `assets/`。
