更新时间：2026-03-21 00:22 Asia/Shanghai

## 0. 目标定义

本次重构不是替换现有系统，而是采用“双系统架构”：

- 现有系统继续保留，负责稳定发布、每日结果展示、复盘查询。
- 新系统单独建设，负责市场理解、行业轮动、策略对照、个股决策与验证闭环。

核心目标：

- 从“策略给股票”升级为“市场—行业—策略—个股—验证”的完整研究决策系统。
- 让最终选出的股票具备现实交易意义，而不是仅停留在排序结果。

## 2. 五层结构

### 2.1 市场层

回答问题：

- 今天是什么市场？
- 当前适合进攻、防守还是观望？

核心输出：

- 市场状态标签
- 风险偏好状态
- 风格偏向
- 广度和强弱分布

关键指标：

- 指数趋势（沪深300 / 中证全指 / 创业板）
- 上涨家数 / 下跌家数
- 涨停 / 跌停分布
- 成交额变化
- 风格轮动（红利 / 成长 / 小票 / 大票）

### 2.2 行业层

回答问题：

- 真正的市场主线行业是谁？
- 哪些行业在升温、降温或拐点？

核心输出：

- 全市场行业热力图
- 行业趋势折线图
- 行业信号卡
- 行业热门股票
- 行业全景看板

关键指标：

- 行业热力值
- 行业热力 EMA(5)
- 3日 / 5日斜率
- 行业排名变化
- 行业平均涨跌幅
- 上涨占比 / 强势股占比
- 成交额占比
- 拥挤度 / 过热惩罚

### 2.3 策略层

回答问题：

- 我的策略有没有踩中市场主线？
- 有没有漏掉真正值得做的行业？

核心输出：

- 策略行业热力图
- 策略 vs 市场对照
- 命中行业 / 漏掉行业 / 偏离行业
- 策略风格漂移

关键指标：

- 行业重合度
- 行业偏离度
- 命中率
- 漏检率
- 策略候选池行业分布

### 2.4 个股层

回答问题：

- 最终该关注哪些股票？
- 这些股票属于什么角色、为什么值得做？

个股对象模型：

- `trade_date`
- `ts_code`
- `stock_name`
- `industry_name`
- `theme`
- `source`
- `strategy`
- `role_type`（龙头 / 跟风 / 补涨 / 策略命中 / 漏检候选）
- `stage`
- `confidence`
- `buy_zone`
- `stop_loss`
- `invalidation`
- `plan`
- `ai_summary`
- `risk_tags`
- `catalyst_tags`

### 2.5 验证层

回答问题：

- 这些结论有没有现实意义？
- 哪些规则真正有效？

核心输出：

- 回测工作台
- T+1 / T+3 / T+5 / T+10 结果
- 行业有效性验证
- 个股命中验证
- 买点 / 止损有效性验证

## 5. 现实意义的硬标准

新系统不能只做“更漂亮的页面”，必须满足以下硬标准：

### 5.1 先市场后个股

- 先判断市场环境
- 再判断行业主线
- 最后才落到个股

### 5.2 先行业后个股

- 个股必须放在行业背景下解释
- 不能脱离行业单独推荐

### 5.3 区分角色

- 龙头
- 跟风
- 补涨
- 观察
- 漏检候选

### 5.4 必须有计划

每只股至少要给出：

- 为什么关注
- 什么时候能做
- 做错怎么撤
- 做对怎么拿

### 5.5 必须有验证

- 回测
- 复盘
- 行业有效性验证
- 个股命中验证

### 5.6 必须做策略 vs 市场对照

这是新系统最独特、也最有价值的一层。
