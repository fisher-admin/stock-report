# micro_v1：尾盘微观结构（分笔主动买卖 + 1 分钟路径）能否提升做多头部的识别 —— 预登记规格

写定时间：2026-11-14 13:15（Asia/Shanghai），写在读取任何分笔数据与收益之前。

## 1. 问题
在 gap 模型（纯隔夜做多，v2 逐月滚动）已经选出的"每日预测前 30 只"里，用 14:45 之前（或 14:56 之前）的分笔主动买卖与分钟路径，能否更准地挑出真正隔夜大涨的股票、并更准地估计幅度？

两段式结构的理由：
- 分笔数据只需对头部股票取，实盘 14:45:30 只多拉约 30 次请求；
- 头部之外的股票已被现有模型判定为"不值得做"，在那里提升排序没有交易价值。

## 2. 数据（tdx /api/trade，分钟级时间戳，Status 0 主买 / 1 主卖 / 2 中性）
- 样本：每日 gap 预测前 30 只，共三组：
  - dev：研究股票，2024-01 至 2026-06，18030 个股票日；
  - wf800：留出 800 只，同一时段，18030 个股票日；
  - time：冻结模型，2026-07-02 至 10-08，1950 个股票日。
- 分笔就地聚合成每分钟：末价、最高、最低、主买额、主卖额、中性额、笔数、大单（单笔 ≥ 20 万元）主买/主卖额、超大单（≥ 100 万元）主买/主卖额；另有 09:25 竞价价与量。

## 3. 两种执行协议
- **A（与影子一致）**：14:45:30 决策，只用分笔时间 < 14:45 的分钟；以 14:55 线均价买入，次日开盘卖。标签 y_A = y_gap。
- **B（新）**：14:56:30 决策，只用分笔时间 < 14:56 的分钟；在收盘集合竞价（14:57–15:00）以收盘价买入，次日开盘卖。标签 y_B = 次日开盘 / 当日收盘 − 1（即 v2 网格的 a_eclose = 0 加 b_xopen）。
- B 多用了 11 分钟的信息，代价是买入价变成收盘价。

## 4. 特征（每个协议各算一套，截止时刻 C = 14:45 或 14:56）
| 名称 | 定义 |
|---|---|
| ob_day | (主买额 − 主卖额) / (主买额 + 主卖额)，09:30 至 C |
| ob_pm | 同上，13:00 至 C |
| ob_30 / ob_10 | 同上，C 之前 30 / 10 分钟 |
| lg_ob_day / lg_ob_30 | (大单主买 − 大单主卖) / 全部成交额，全天 / 近 30 分钟 |
| xl_ob_day | 超大单净主买 / 全部成交额，全天 |
| lg_share_30r | 近 30 分钟大单成交额占比 ÷ 全天大单占比 |
| size_30r | 近 30 分钟平均每笔成交额 ÷ 全天平均 |
| intens_10r | 近 10 分钟每分钟笔数 ÷ 全天每分钟笔数 |
| amt_10r | 近 10 分钟成交额 ÷ 全天每 10 分钟平均 |
| ret_10 / ret_30 | 近 10 / 30 分钟价格变化 |
| up_share_30 | 近 30 分钟里分钟末价上涨的分钟占比 |
| dd_30 | 近 30 分钟最大回撤（相对区间最高价） |
| vwap_dev_30 | 末价 / 近 30 分钟成交均价 − 1 |
| kyle_60 | 近 60 分钟逐分钟收益对"主买额 − 主卖额"（除以全天每分钟均额）的回归斜率 |
| auc_share | 09:25 竞价成交额 / 截至 C 的全天成交额 |
| ob_open30 | 09:30–10:00 的主买卖差 / 合计 |
| ob_flow_corr_60 | 近 60 分钟主买卖差与分钟收益的相关 |

共 20 个（写定时把数目误记为 19，特征表本身未改；2026-11-14 13:40 读数据前更正）。进模型前在当日头部 30 只内部做截面百分位秩。

## 5. 模型与对照
- **基线 M0**：头部内按 pR_gap 排序；做多规则沿用 pR_gap > 成本取前 5。
- **新模型 M1**：LightGBM 回归，特征 = pR_gap 原值 + pR_gap 的头部内秩 + 20 个微观特征的头部内秩 + 当日头部 30 只的 pR_gap 均值。
  - 目标：对应协议的 y，截尾 ±6%。
  - 参数：num_leaves 7，min_data_in_leaf 200，learning_rate 0.03，150 轮，feature_fraction 0.8，bagging 0.8，lambda_l2 10。
  - 训练：只用 dev，逐月扩展窗口（2024-01 起，前 6 个月只训练），样本外 2024-07 至 2026-06。
- **做多规则（M1）**：头部里 M1 预测 > 成本的前 5 只；协议 B 每笔同样扣 19.2bp。

## 6. 关卡（只看 dev 样本外，写定后不改）
1. **头部排序**：M1 的日内秩相关减 M0 的日内秩相关，在 2024-07 至 2025-12 段 t ≥ 2，并且在 2026H1 为正。
2. **头部幅度**：M1 预测最高的 5 只的每笔毛收益，比 M0 前 5 只（同一天、同一头部）高 ≥ 10bp，并且在 2024H2、2025、2026H1 三段都为正。
3. **账本**：M1 规则的每笔毛收益 ≥ M0 规则 + 10bp，且开仓日数不少于 M0 的 70%。

三条都过的协议（A 或 B；都过则取账本每笔毛更高者）冻结为 micro_v1，然后：
- wf800 读一次：用 dev 训练、截至 2026-06 的模型，套在 wf800 头部上，2024-07 至 2026-06；
- time 读一次：2026-07 至 10-08。
记录写入 `outputs/overnight_v0/micro_v1/READ_LOG.json`。
