# Wave1 · 影子常态化挂闭环 — 实施报告

- 日期: 2026-07-11 (周六) · 轨道: 保护三层闸影子重放常态化
- 决议依据: B-4 影子常态化一周(7/11起), 7/18后拍板接线第18族

## 做了什么

1. **读 spike4 入口**: `spikes/spike4_protection/shadow_replay.py` 提供 `run_shadow(out_dir)`
   —— recommendations.db 只读(mode=ro) → as-of 截断台账 → MemLockStore 纯内存注入重放
   → 三列报告(lock_effective_date/blocked_rec/posthoc_excess_5d)+事件流+MARKET_STRESS 多档分布。
   `run_shadow(None)` 只跑引擎不落 spike 目录文件(零残留)。

2. **新增 wrapper** `ops/run_protection_shadow.sh`:
   - `sys.path` 注入 spike 目录, `import shadow_replay`, 调 `run_shadow(None)`;
   - MARKET_STRESS 取**已拍板 5% 档**(`MARKET_STRESS=${MARKET_STRESS:-0.05}`, 可环境变量覆盖调参);
   - 组装 JSON 落 `stock_data/03-working/health/protection_shadow_latest.json`
     + 按日存档 `protection_shadow_archive/protection_shadow_YYYYMMDD.json`;
   - JSON 含: 三列被挡明细(锁生效日/被挡推荐/被挡后验超额5日) + 5%档 MARKET_STRESS 触发日清单
     + 落锁清单 + 后验超额汇总(均值/中位/负占比)。

3. **接线收盘链** `ops/run_daily_closure.sh` 末尾追加**非致命**步骤(`|| echo ... non-fatal`),
   注释标注 B-4决议/影子常态化一周/7-18后拍板接线第18族。
