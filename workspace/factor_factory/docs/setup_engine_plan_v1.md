# 因子策略重造方案 v2:剧本引擎(Setup Engine)(2026-07-03)

> 前置证据(全部实测冻结): 无条件横截面因子在"A股长多+真实成本"下全灭(价量/基本面/慢风格/日内);
> 唯一走完全套证伪流程的幸存者=竞价弱转强(WTS)——一个【T日条件 × T+1决策点触发 × 固定出场】的条件形态。
> 数据资产(已就位): 全历史面板1303日×184列 / 开盘+收盘竞价2022-2026全量1164万行 / 800只5min研究样本
> +800只holdout / 实测滑点·容量表 / 因子闯关机 / WTS前瞻跟踪装置。

## 0. 范式转变:为什么必须换架构

**旧范式(已证伪)**: 每日给全市场2300只按因子composite打分→取top N。
死因是结构性的: ①横截面打分吃的是"平均边际",被成本磨平; ②强信号在不可交易侧;
③一个分数对所有市况一视同仁,而A股的短线机会是**regime依赖**的(WTS年表: 2022-23零/2024爆发/2025-26衰减)。

**新范式(Setup Engine)**: 不再问"哪只股票分最高",改问**"今天哪个剧本被触发了,触发的那几只值不值得打"**。
剧本(Setup)= 稀疏条件事件 × 合法决策点触发 × 固定出场 × 执行现实闸。
因子不再是alpha本身,降级为剧本内的**条件变量与触发后排序**。

## 1. 三层架构

```
第1层 Regime闸(何时允许开火) ————— 市场级: 涨停家数/连板高度/成交额/行业热度加速(面板sector_regime_id
  │                                从未被使用!) → 每个剧本声明自己的适用regime,不适用时禁火。
  │                                直接回应WTS年表暴露的regime依赖——这是"命中质量"的第一杠杆。
第2层 Setup剧本库(打什么) ————————— 每个剧本: T日条件(稀疏,全市场→几十只) × T+1决策点触发
  │                                (9:25竞价/15:00收盘竞价——合法早决策点) × 固定持有出场规则。
  │                                统一注册表 setup_registry.json,闯关→冻结→前瞻,同一生命周期管理。
第3层 执行现实闸(能不能打/打多大) ——— 实测滑点表(B1)分档计成本;竞价成交额定仓位上限(≤10-20%);
                                   一字/顶死高开剔除;每日总触发数限流。
```

## 3. 回测与验证协议(统一引擎,一个剧本一天出结论)

**引擎**: 扩展 factor_gauntlet → `setup_gauntlet.py`(--setup 模式):
输入=registry里的剧本定义,自动执行:
1. **事件样本构建**: 全历史面板×竞价/分钟数据,按定义生成全部触发事件(去缺口边缘/一字剔除);
2. **五道闸**(在四道闸上加一道):
   - 闸1 三段分解(edge必须在可成交段)
   - 闸2 净边际: **成本=佣金印花+B1实测滑点表对应档**(不再用统一30bp拍脑袋),要求净>0且t>2
   - 闸3 独立复现: universe分半 + **时间切分强制逐年表**(regime诚实,WTS的教训制度化)
   - 闸4 安慰剂: 触发特征日内打乱×10
   - **闸5 容量与频率**: 年触发数/日均触发数/触发股竞价额分位——报告"这个剧本一年给你几次机会、每次能上多少钱"
3. **判定**: 全过=CANDIDATE→冻结进 registry(签名)→自动接入每日前瞻ledger(复用WTS跟踪装置,60笔审判制);
   任一FAIL=REJECTED入档,死因记录,同定义不得重测。

**基线对照(量化"提升")**:
- 命中质量基线: 现有观察清单 T+1 胜率 ~44-50%(复盘实测)、WTS样本内幸存桶 50-58%;
- 目标: S6确认子集胜率较原清单 **+5pp以上且过闸3**; 新剧本要求触发后净期望>0(实测成本口径);
- 效率基线: 旧研究一个想法数周 → 引擎目标 **一天一个剧本出终审结论**(闯关机已证明可行)。

## 5. 不做清单(铁律继承)
- 不做全市场无条件composite的"再优化"; 不碰holdout 800只(留给幸存剧本的终审复现);
- 不在样本内给任何剧本宣布"可部署"——幸存=上前瞻裁判席(60笔审判制),仅此而已;
- 不用低于实测表的滑点自我安慰; 不给已REJECTED的定义换皮重测;
- ML(GBDT)只允许在**已幸存剧本内部**做触发后排序(特征≤20+CPCV),不允许全市场钓鱼。

## 6. 诚实边界
- 决策点可执行性: 竞价数据的盘中实时可得性未验证(前瞻ledger按收盘后记账不受影响;若未来要盘前实盘执行,需另验数据延迟);
- 分钟特征只覆盖800只研究样本(结论需在holdout复现才算数);
- WTS年表已证明这类形态会衰减——**前瞻ledger就是持续的衰减监测器**,每个幸存剧本自带kill规则;
- 最可能的结局分布: 6个剧本大概率2-4个全灭、1-2个以微边际幸存进裁判席——这就是诚实研究的正常产出率。
